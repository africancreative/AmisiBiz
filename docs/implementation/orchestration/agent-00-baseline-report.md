## 1. Deliverable A — Repository Assessment

### 1.1 What the repository is

AmisiBiz is an existing, functional multi-tenant SaaS application — a Social Commerce / Mini-CRM / Marketing Intelligence platform for Kenyan and East African businesses — deployed as a pnpm 11 + Turborepo monorepo (12 workspace packages) with a Next.js 15 App Router web app (`apps/web`), retired-but-preserved Capacitor/Tauri shells (`apps/mobile`, `apps/desktop`), and nine shared packages (`packages/auth`, `database`, `documents`, `domain`, `integrations`, `offline`, `sync`, `ui`, `config`).

The primary database is **Neon PostgreSQL**, managed exclusively through Prisma 6.19 with a 22-migration forward-only chain. Row-Level Security is deployed live with the `amisibiz_app` role grants in place. Authentication is native Web Crypto HMAC-SHA256 sessions with `sessionVersion` instant revocation; RBAC is a 9-role model over a 57-key permission matrix in `@amisibiz/auth`.

## 4. Deliverable D — Canonical Architecture (locked)

Reconfirmed without substitution, per the directive:

1. **Stack:** Next.js 15 App Router, TypeScript strict, Tailwind + `@amisibiz/ui` primitives. No rebuilds; existing subsystems evolve in place absent empirical defect proof.
2. **Database:** Neon PostgreSQL via Prisma 6.19, single schema authority, forward-only migrations, RLS defense-in-depth. **Supabase is not to be reintroduced.**
3. **Hosting:** **Vercel for the web application**; private cloud object storage for tenant files and PDFs (provider pending O4).
4. **Tenancy:** subdomain isolation (`<slug>.amisibiz.com`), server-enforced membership, `PENDING`/`ACTIVE`/`SUSPENDED` state machine with write-gate triggers preserving reads.
5. **Money & tax:** KES default with explicit ISO codes; string-based fixed-decimal arithmetic only; configurable taxation; commercial documents are never presented as KRA/eTIMS tax invoices, and no eTIMS transmission may be introduced or claimed.
6. **Onboarding & billing:** Amisi Genuine-controlled provisioning; manual, information plans; suspension is an operator decision with mandatory audit reasoning; no automated payment-gateway suspension flows.
7. **Security:** deny-by-default RBAC over the 57-key catalog; server-side authorization only; client inputs never trusted for tenant/role/price/total/status; secrets never in bundles, logs, or errors.
