## 2. Integration Hardening Contracts

1. **Timeout Bounds:** All third-party outbound HTTP requests must enforce an explicit timeout (maximum 10,000ms).
2. **Idempotency:** Webhook ingestion endpoints (DPO, M-Pesa, WhatsApp) must enforce deduplication using webhook event IDs.
3. **Audit Trail:** Every outbound dispatch to a regulatory (eTIMS) or financial (DPO Pay) service must be recorded in `AuditLog`.
4. **Secret Protection:** Integration tokens and private keys must never be logged or returned in error payloads.
